## Credits and how I use these repos

- All the work in the repositories above belongs to their authors. I link to the originals first, and keep forks only so I can study and experiment with the code.
- Forks keep their original commit history, author attribution and licence files.
- **Football-analytics** has no licence file, so by default its author keeps all rights. My fork is for personal learning only; I won't redistribute or reuse its code or data without Victoria's permission.
- **gunners-analysis** is MIT-licensed. Any code I reuse from it will keep the copyright notice and licence text.
- **human-agentic-data-analysis** is shared under Creative Commons Attribution 4.0. Anything I reuse from it will name its creators (Vivid Insights and David Sumpter), link the original and the licence, and say what I changed.
- If you're one of the authors and you'd like anything changed or removed, please [open an issue](https://github.com/mbusani/football-analytics-lab/issues) and I'll fix it promptly.
