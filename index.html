Football-analytics

Victoria Friss de Kereki@vickyfriss · Football data analyst

A growing collection of notebooks that explore football, and sometimes rugby, through data, using pandas, scikit-learn and matplotlib.

  • xG and expected-pass models for women's football
  • Wage vs performance in English football
  • Pass clustering and passing networks (FC Barcelona)
  • League-position simulations from betting odds
  • Pizza charts and StatsBomb formation plots
  • Rugby Premiership forecasting

Python pipeline

gunners-analysis

Muhammad Atef@Muhammadatef

Automated football analytics for Arsenal: data is scraped, transformed and stored without manual steps, then turned into tactical dashboards and an AI analyst that answers only from the stored data.

  • Apache Airflow orchestration
  • PostgreSQL warehouse with pgvector
  • 18-panel tactical dashboards (mplsoccer)
  • LLM analyst built with DSPy
  • Scrapers, data-quality checks and tests
  • Docker setup and deployment notes

Claude Code template

human-agentic-data-analysis

David Sumpter · Vivid Insights@soccermatics · Vivid-Insights

A template workspace for doing a data analysis with an AI agent one step at a time, so the judgement calls stay with the analyst and the report can be defended.

  • Obsidian vault with a working contract for the agent
  • Eight steps, from data import to export
  • Report and appendix templates that fill as you go
  • A sample report on World Happiness data
  • Python environment and figure style
  • Standing disclaimer on AI assistance
