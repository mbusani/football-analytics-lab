Football-analytics

Created byVictoria Friss de Kereki

A growing collection of notebooks that explore football, and sometimes rugby, through data, built with pandas, scikit-learn and matplotlib.

  • xG and expected-pass models for women's football
  • Wage vs performance in English football
  • Pass clustering and passing networks
  • League simulations from betting odds
  • Pizza charts and formation plots
  • Rugby Premiership forecasting

★ 10 stars⑂ 2 forksupdated Oct 2026

gunners-analysis

Created byMuhammad Atef

Automated football analytics for Arsenal: data is scraped, transformed and stored with no manual steps, then turned into tactical dashboards and an AI analyst that answers only from the stored data.

  • Apache Airflow orchestration
  • PostgreSQL warehouse with pgvector
  • 18-panel tactical dashboards (mplsoccer)
  • LLM analyst built with DSPy
  • Scrapers, quality checks and tests
  • Docker setup and deployment notes

human-agentic-data-analysis

Created byDavid Sumpter · Vivid Insights

A template workspace for doing a data analysis with an AI agent one step at a time, so the judgement calls stay with the analyst and the report can be defended.

  • Obsidian vault with a working contract
  • Eight steps, from import to export
  • Report and appendix that fill as you go
  • Sample report on World Happiness data
  • Python environment and figure style
  • Standing disclaimer on AI assistance
