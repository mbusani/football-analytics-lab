  • LLM analyst built with DSPy
  • Scrapers, quality checks and tests

analytics_cup_research

Created byHadi Sotudeh

Positional player scouting with tracking data: working out which position a player actually plays, phase by phase, so scouts can find the matches where a versatile player filled the role they're recruiting for. A finalist in the Research Track of the SkillCorner X PySport Analytics Cup 2026.

  • 5×5 grid around a team's outfield players
  • Position maps: share of match time per cell
  • Split by in and out of possession
  • Broken down by SkillCorner sub-phases
  • Position templates from 267 players
  • Submission notebook and player maps

football-docs

Created bywithqwerty · Rahul Keerthi

Like Context7 for football data: searchable documentation that AI coding agents can look up, so they use the real event types, coordinates and API details instead of guessing from training data.

  • Docs for 32 data providers and tools
  • StatsBomb, Opta, SkillCorner, Wyscout and more
  • kloppy, mplsoccer, socceraction and other libraries
  • Compares how providers handle a concept
  • Matches players and teams across provider IDs
  • Checked metric definitions and source papers
