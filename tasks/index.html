How this works

Tracked with BeadsTasks live in Beads, the open-source, MIT-licensed task tracker for coding agents by Steve Yegge. I run it on my own computer with Claude Code.
Read from GitHubBeads keeps a plain-text copy in .beads/issues.jsonl. When I push my lab to GitHub, this page reads that file and redraws the board.
On my computerbd ready lists what I can start, bd close finishes a task, and Beads Viewer by Jeffrey Emanuel shows the same board in the terminal.
