The data

Every session uses the same small extract of StatsBomb's free event data for the 2022 FIFA World Cup: 64 matches, 829 players and every shot. Download it to keep practising offline.

For SQLwc2022.sqlite: one SQLite database with all three tables. Open it in DB Browser for SQLite or DuckDB.
For Python and Rmatches.csv, players.csv and shots.csv: load them with pd.read_csv or read.csv.
Rebuild itbuild_wc2022.py downloads the data from StatsBomb and builds all four files.

Credits

The data is StatsBomb's, used under the StatsBomb Public Data User Agreement. The sessions run on sql.js, Pyodide with pandas, and webR with dplyr. Everyone is credited on the Credits page.
