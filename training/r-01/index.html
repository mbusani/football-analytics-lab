The squad sheet

03

Three data frames built from StatsBomb's free event data for the 2022 FIFA World Cup: matches, players and shots, with dplyr already loaded. Each was read with read.csv("shots.csv"), and you can download the same files to work offline.

Read before kick-off
  • End a drill with the table or number you want as the last line, or store it in a variable called answer.
  • |> is R's pipe: shots |> filter(period < 5) means filter(shots, period < 5). Read it as "and then".
  • period == 5 is a penalty shootout. Shootout kicks are in shots but don't count as goals in the score, so most drills leave them out with filter(period < 5).
  • xg is StatsBomb's expected goals for the shot: the chance an average shot from that spot and situation goes in.
  • Text matches are exact and case-sensitive: "Argentina" works, "argentina" doesn't.
