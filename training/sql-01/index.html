The squad sheet

03

One small SQLite database built from StatsBomb's free event data for the 2022 FIFA World Cup. It has three tables. Keep this sheet open while you work: every drill uses these column names.

Read before kick-off
  • period = 5 is a penalty shootout. Shootout kicks are in shots but don't count as goals in the score, so most drills leave them out with WHERE period < 5.
  • Own goals aren't shots, so goals counted from shots won't always match the scoreline.
  • xg is StatsBomb's expected goals for the shot: the chance an average shot from that spot and situation goes in.
  • x and y are on StatsBomb's 120 × 80 pitch, with every team attacking towards x = 120.
  • Text matches are exact and case-sensitive: 'Argentina' works, 'argentina' doesn't.

Drills

08

Write a query, press Run (or Ctrl+Enter) to see what it returns, then Check it against the answer. The checker compares values, not column names, so call your columns whatever you like. Your queries and ticks are saved in this browser.
